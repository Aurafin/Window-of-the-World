## 安全建议

代理节点本质上位于你的设备和目标网站之间。

因此：

- 重要网站尽量确保使用 HTTPS；
- GitHub 推荐 SSH / HTTPS；
- 重要账号开启 MFA 或 Passkey；
- 不要在来路不明的代理节点上传输特别敏感的信息；
- 公司生产环境不要依赖个人代理作为正式网络方案。
